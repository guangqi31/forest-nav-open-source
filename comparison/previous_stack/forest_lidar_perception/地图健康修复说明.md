# 地图健康三项修复

2026-11-13，默认一键启动已使用修复代码。历史问题与复现见地图健康诊断报告.md；本文件描述最终实现和验证。

## 修改内容

1. **慢仿真误停**：模拟器在每个实际执行的仿真步写入独立轻量进度文件，雷达桥不再把等待下一次正常仿真采样的墙钟间隔当成断流。健康心跳与点云分开：/lidar/status持续报告状态，/lidar/points等只发布实际新帧。雷达测量使用两个采样周期的仿真年龄，地形使用三个周期；当前分别0.4/0.6仿真秒。
2. **迟到帧清图**：TerrainGrid只忽略时间更旧的消息，不再自行reset。地图清空由明确的重置服务、源会话/时钟代号变化、或实际/clock回退触发，不能由一帧乱序消息触发。
3. **坏帧撤销有效历史**：坏帧只记录拒收，不清除此前有效测量的时间，也不延长它。连续收不到有效测量，旧观测超过仿真年龄限值后仍会停止。
4. **保留停止链**：步进心跳和仿真时钟推进0.5墙钟秒失联、雷达桥状态心跳1墙钟秒失联，以及原机器人反馈/控制许可/UDP指令看门狗继续有效。地图重置增加reset_generation，安全监视和上层管理器均能终止旧任务，防止重置后很快恢复ready掩盖旧任务失效。

未修改InstinctLab、IsaacLab核心、G1 ONNX策略、速度参数或Nav2规划器/足迹配置。进度文件属于本项目的仿真传感器接口，不是新增训练或控制器。

## 自动检查

针对性25项通过，包括：

- 2.4墙钟秒只推进0.16仿真秒时，地图继续有效；旧点云仅发布一次，地形有效时间未被心跳刷新。
- 雷达停止而仿真继续、CMU停更、仿真暂停、雷达桥/地图节点/状态桥失联时，许可撤销或接收端归零。
- 单个未来帧不会中断仍新鲜的地图；持续坏帧最终使有效观测过期，仍归零。
- 迟到帧保持全局历史；实际时钟回退仍清图并终止旧任务。
- 地图持久/局部过期、保存与重置、探索、取消、替换、故障和恢复预算保持有效。

随后在同一上层任务测试中加入“地图重置后立即恢复ready”场景，相关4项再次通过，旧任务因map_reset退出且不重发。这4项与25项有重叠，不应累计说成29项。

接口检查使用受控时间与真实本机UDP。取消入口或Nav2客户端部分使用夹具；它们不替代真实仿真运动和物理停稳验收。
