# 地图范围外目标接纳

在线激光模式下，坐标面板、命令行客户端及 `/navigation/navigate_to_goal` 现在允许当前地图边界外的最终目标进入有限探索。重启原一键入口加载即可，不需要新启动脚本。离线模式保持原准入规则。

范围外目标仅表示探索方向，没有对应栅格，`cost=None`；不能因此分配地图、填自由格或把远目标直接下发原生Nav2。流程为：范围外终点 → 已知安全观察点（原Nav2检查路径）→ 接收真实观测并扩图 → 图内未知终点 → 终点观测到且代价不超过25 → 原Nav2最终导航。每轮都重新检查地图；后续发现终点禁行或停稳代价过高会结束任务。

沿用每任务最多12段、6次失败、默认240墙钟秒和每段70墙钟秒的原预算，以及地图/定位健康、会话、取消、替换与停止保护。目标太远、达到最大地图尺寸或没有可达前沿时，任务可以明确受阻；接纳不代表保证到达，不会无限探索。

`/navigation/exploration_status` 新增 `initial_target_outside` 和 `target_outside_current_map`。初始范围外也属于 `initial_target_unknown=true`；等待探索时原因码为 `target_outside_current_map`。离线严格准入仍返回 `outside`。

实现位置：`nav2_path_tracking/forest_nav_control/goal_validation.py`、`task_client.py`、`coordinate_controller.py`、`unknown_navigation.py`。地图扩展、Smac规划器、G1策略和安全阈值未修改。

验证：15项针对性检查通过，包含真实ROS Action通信下“图外→扩图→最终导航”、无新观测的有限终止，以及原取消/替换/故障停止。感知、规划及运动服务为夹具；本轮没有运行新的Isaac物理行走，之前(1,10)那次属于图内未知目标，不能当作本功能的图外行走证据。机器可读结果见 `results/outside_goal_admission/verification.json`。
